# CRA, NIS2 and NIST SSDF crosswalk

> Cite as: CVD Portal, "CRA, NIS2 and NIST SSDF crosswalk", 2026-10-17. https://cradata.eu/crosswalk (CC BY 4.0)

Each requirement of the Cyber Resilience Act (Regulation (EU) 2024/2847) Annex I and Articles 13(5) and 14, mapped to the NIS2 Directive (EU) 2022/2555 provisions and NIST SSDF 1.1 practices that ask for the same or a related outcome.

The page of this dataset is https://cradata.eu/crosswalk. Read the method and the limits there before you use a figure.
